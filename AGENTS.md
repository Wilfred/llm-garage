## Repository

Always do your work in a git worktree so you don't dirty the current
checkout.

## Commit Style

Keep commit messages concise, don't use headings unless you have a
large amount of text. Prefer sentences over bullets. Don't list checks
that you've done to validate unless they're notably different from
what CI runs.

## Naming

The product is called "LLM Garage". Use that spelling in all
user-facing text. `llm-garage` is only the repository, package and
Docker image name.
